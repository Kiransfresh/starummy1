# Star Rummy 1.7.39 backend

Optional split proposals are enabled by default between rounds for two-player tables and six-seat tables with two or three survivors. All participants must agree. Decline or expiry resumes normal rounds. Integer token settlement, idempotent transactions, player scores, rejoin eligibility and existing funded pool snapshots are unchanged. Explicit administrator restrictions remain respected.

The Android companion build improves mobile scoreboard fit and retains the previous plans/drop UI.
